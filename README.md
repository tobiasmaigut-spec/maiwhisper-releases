# MaiWhisper – Downloads und Updates

Lokales Diktieren für macOS (Apple-Chip, ab macOS 12). Dieses Repository enthält **nur** die fertigen Programmdateien, keinen Quellcode.

- **Neueste Version herunterladen:** [MaiWhisper.dmg](https://github.com/tobiasmaigut-spec/maiwhisper-releases/releases/latest/download/MaiWhisper.dmg)
- Alle Versionen und Versionshinweise: [Releases](https://github.com/tobiasmaigut-spec/maiwhisper-releases/releases)

Installierte Apps ab Version 3.3 finden neue Versionen selbst (einmal täglich, mit Rückfrage vor der Installation). Dafür lädt MaiWhisper nur die Datei `appcast.xml` aus dem neuesten Release – keine Aufnahmen, Texte oder Nutzungsdaten. Jedes Update ist mit einer EdDSA-Signatur versehen; veränderte Dateien lehnt die App ab.

MaiWhisper ist nicht von Apple notarisiert. Beim ersten Öffnen eines heruntergeladenen Disk-Images: Systemeinstellungen › Datenschutz & Sicherheit › **Dennoch öffnen** (siehe Anleitung im Disk-Image).
